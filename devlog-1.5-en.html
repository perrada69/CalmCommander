Calm Commander 1.5 — TR-DOS disk images and colour themes

Version 1.5 adds a viewer for TR-DOS disk images with file extraction, and predefined colour themes that can be switched with a single keypress.

TRD viewer

Files with the .trd extension are now opened by a new viewer plugin that lists the complete TR-DOS catalogue. Point the cursor at an image and press View (3 by default).

  • Every catalogue entry is listed with its name, type, size in bytes, position on the disk (track/sector) and load address.
  • BASIC entries show the length of the program without variables instead of the load address.
  • The title line shows the disk geometry (80T/2S, 40T/1S and so on) and the number of catalogue entries; the header line adds the disk label and the number of free sectors.
  • Deleted entries remain visible and are marked DEL.
  • Entries that point outside the image are marked BAD and are never written to disk.
  • Navigation works the same way as in the TAP viewer: arrows, PgUp and PgDn.

Extracting files from an image

Files stored in the image can be written to the SD card without any external tool. e extracts the entry under the cursor and Caps+e extracts all of them. Files are created in the directory shown in the active panel, and the panel is refreshed when the export finishes.

  • d switches the +3DOS header on and off. With headers enabled (the default) NextZXOS recognises the exported files as BASIC or CODE, together with their line number and load address.
  • BASIC files are saved with the .BAS extension, everything else as .BIN. Names that TR-DOS allows but a FAT card does not are sanitised automatically.
  • A deleted entry can still be exported individually, which makes it possible to rescue data from a file that TR-DOS has already dropped from its catalogue. Bulk export skips deleted entries.
  • During the export the plugin shows the target name, its length, a WORKING... indicator and a file counter, so a longer export never looks like a frozen program.

Images of every common size are supported — 160K, 320K and 640K. Because a disk image is far larger than the memory the viewer keeps a file in, data is read directly from the image at the exact position of the requested file, so files stored in the outer tracks are extracted just as reliably as those at the beginning of the disk.

Colour themes

The Colours tab in the Settings window (Caps+S) starts with a new Colour scheme row. Pressing Enter on it cycles through the prepared themes: Default, Light and Dark.

  • Selecting a theme rewrites all sixteen interface styles at once and is applied immediately, so the result is visible while choosing.
  • Each style can still be adjusted separately — background and foreground are set as R/G/B values from 0 to 7. The list covers the panel cursor, marked files, directories, executable files, dialogs, the viewer and the colours used by plugins.
  • As soon as an individual colour is edited, the scheme is reported as Custom.
  • S saves the configuration for future sessions, BREAK cancels the whole editing session and restores the previous colours.
