Calm Commander 1.4 — bookmarks, settings and loading feedback

Version 1.4 of Calm Commander brings several quality-of-life improvements focused on faster navigation, customization, and clearer feedback when working with large directories.

Bookmarks

Frequently used directories can now be saved as bookmarks and opened again without navigating through the complete directory structure.

  • Press Shift+B to bookmark the current directory.
  • Press B to open the bookmark list.
  • Bookmark names can contain up to 24 characters.
  • Long file name paths are shown when adding and browsing bookmarks.
  • Opening a bookmark refreshes only the active panel.

Bookmarks are stored alongside cc.cfg. Existing bookmark files using the older format are upgraded automatically without losing saved entries. The complete feature is implemented as an 8 KB plugin to save space in the main program.

Settings

The new Settings window can be opened with Caps+S. It allows you to customize Calm Commander's colours and remap its keyboard shortcuts.

  • Switch between the Colours and Keys tabs with the left and right arrows.
  • Assign your preferred shortcut to every available action.
  • Duplicate shortcuts are detected and cannot be assigned.
  • Caps Shift combinations such as Caps+3 and Caps+C are handled correctly.
  • The Help screen and bottom shortcut bar reflect the customized controls.

The new configuration is saved for future sessions. Settings are also provided as a plugin, keeping the resident part of Calm Commander as small as possible.

Automatic plugin check

Calm Commander now verifies all 16 standard plugin files during startup. When the installation is complete, the check remains silent and startup continues normally.

If one or more plugins are missing, a centred dialog lists their complete file paths. This makes an incomplete installation immediately visible and shows exactly which files need to be restored. Press any key to continue starting Calm Commander.

Loading large directories

Calm Commander now provides visual feedback while a larger directory is being loaded and sorted. After approximately half a second of work, a compact Loading / sorting... message appears inside the active panel.

The message disappears automatically when loading is complete and the panel is redrawn. Small and quickly loaded directories continue to open without an unnecessary popup.
