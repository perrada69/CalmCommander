Calm Commander 1.3 — sorting and new panel options

Version 1.3 of Calm Commander is now available. This update adds several new configuration options for the file panels and improves the overall user experience.

Directories first

You can now choose to display directories before files in both panels. This makes navigating folders faster, especially in directories containing many different files.

File sorting

The new sorting option lets you arrange panel contents by:

  • name,
  • extension,
  • date.

The sorting mode can be changed directly from the Utils menu. The menu stays open while you cycle through the available modes, and the panels are rearranged when you leave the menu.

K-Mouse toggle

K-Mouse support can now be enabled or disabled from the Utils menu. This is useful if you prefer keyboard-only control or if a mouse interface is not connected.

Saved configuration

All the new options are stored in the cc.cfg configuration file, so your preferred directory order, sorting mode, and K-Mouse setting are restored the next time Calm Commander starts.

Bug fixes

Version 1.3 also includes several small fixes and menu improvements for a smoother and more reliable experience.

Thank you for using Calm Commander!
